LOVE WEBSITE - QUICK SETUP

1. Put your music file in this folder and name it: music.mp3
2. Put your photos here and name them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg

3. Open script.js and change:
   const PASSWORD = "love123";
   to your own password.

4. Open index.html in your browser to test it.

5. To publish for free:
   - Create a GitHub account.
   - Create a NEW PUBLIC repository.
   - Upload all files in this folder.
   - Open Settings > Pages.
   - Under Build and deployment choose "Deploy from a branch".
   - Select the main branch and / (root), then Save.
   - GitHub will give you a free website link.

IMPORTANT:
Use your own music or music you have permission to publish.
